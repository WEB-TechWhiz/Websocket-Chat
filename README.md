## 📌 Overview
**Websocket-Chat** is designed to provide a comprehensive, maintainable, and scalable solution in the **Real-Time / Communication** domain. Engineered with modern industry standards and clean architecture.

---

## ✨ Key Features
- **Real-Time Messaging**: Sub-millisecond latency bi-directional message dispatch
- **Rooms & Channels**: Create and join public and private chat channels
- **User Presence**: Live online/offline status indicators and typing indicators

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18.x or higher recommended)
- **npm**, **yarn**, or **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/WEB-TechWhiz/Websocket-Chat.git
   cd Websocket-Chat
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```


5. **Start the development server:**
   ```bash
   node index.js
   ```
